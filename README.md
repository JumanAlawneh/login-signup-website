# Login & Signup Website 🔐

## 📌 About the Project
A simple and user-friendly website built to demonstrate a login and sign-up interface using HTML, CSS, and JavaScript.

## 🚀 Features
- Login page
- User registration (Sign Up)
- Home page
- Simple and clean user interface
- Client-side interaction using JavaScript

## 🛠️ Technologies Used
- **HTML5** — Website structure
- **CSS3** — Styling and layout
- **JavaScript** — Interactive functionality

## 📂 Project Structure
```text
my-first-project/
│
├── LOGIN.html
├── signup.html
├── home.html
└── README.md
```

## ▶️ How to Run
1. Download or clone this repository.
2. Open `LOGIN.html` in your web browser.
3. Explore the website pages.
