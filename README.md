# Luxe Bags 👜✨

## 📌 About the Project
Luxe Bags is a stylish handbag showcase website built using HTML, CSS, and JavaScript. It features a luxury-inspired black and gold design and allows users to explore a collection of handbags and view their details.

## 🚀 Features
- Login page
- User registration (Sign Up)
- Home page with a luxury-inspired design
- Handbag collection with product images
- Individual product details pages
- Product prices and descriptions
- Quantity selection
- Add to Bag functionality using browser local storage
- Add and remove favorite handbags
- Responsive design for different screen sizes
- Interactive functionality using JavaScript

## 🛠️ Technologies Used
- **HTML5** — Website structure
- **CSS3** — Styling, layout, and responsive design
- **JavaScript** — Interactive functionality and product handling
- **Local Storage** — Saving favorites and bag items in the browser
- **GitHub Pages** — Website hosting

## ▶️ How to Run
1. Open the live demo link to explore the website.
2. Browse the handbag collection.
3. Select **View Details** to see a handbag's information.
4. Choose a quantity and click **Add to Bag**.
5. Use the **Favorite** button to save your favorite handbags.

You can also download or clone the repository and open `LOGIN.html` in your browser.
