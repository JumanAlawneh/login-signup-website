# Luxe Bags 👜✨

A Luxury Handbag Showcase Website

## 📌 About the Project

Luxe Bags is a luxury-inspired handbag showcase website built using HTML, CSS, and JavaScript. It features an elegant black and gold design where users can explore handbag collections, view product details, choose quantities, and save their favorite items.

## 🚀 Features

- 🔐 Login page
- 📝 User registration page
- 🏠 Home page with a luxury-inspired design
- 👜 Handbag collection with product images
- 🔎 Individual product details pages
- 💰 Product prices and descriptions
- 🔢 Quantity selection
- 🛍️ Add to Bag functionality using browser Local Storage
- ❤️ Add and remove favorite handbags
- 📱 Responsive layout for different screen sizes
- ✨ Interactive elements using JavaScript

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, layout, and responsive design
- **JavaScript** — Interactive functionality
- **Local Storage** — Saving favorite items and bag contents in the browser
- **GitHub Pages** — Website hosting

## ▶️ How to Use

1. Open the live website.
2. Browse the handbag collection.
3. Select **View Details** to explore a handbag.
4. Choose a quantity and click **Add to Bag**.
5. Click **Favorite** to save or remove a handbag from your favorites.

You can also download or clone the repository and open `LOGIN.html` in your browser.

## 🎯 Project Goal

This project was created to practice front-end web development, improve HTML, CSS, and JavaScript skills, and build an interactive product showcase website.
