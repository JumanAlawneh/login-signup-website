## ✨ The Story Behind Luxe Bags

Luxury is more than what you carry — it's how you express yourself.

**Luxe Bags** is a luxury-inspired handbag showcase designed to bring sophistication and style into one elegant digital experience. Featuring a sleek black-and-gold aesthetic, the website invites visitors to explore a curated collection of handbags, discover product details, and find pieces that match their personal style.

Built with **HTML, CSS, and JavaScript**, this project combines fashion-inspired visuals with interactive front-end functionality.

## 🖤 The Visual Identity

Luxe Bags embraces a sophisticated visual language inspired by luxury fashion.

- **Midnight Black** — bold, timeless, and elegant.
- **Signature Gold** — a refined touch of luxury.
- **Minimal Layouts** — clean presentation that lets the collection stand out.
- **Interactive Details** — subtle transitions and engaging user experiences.

Every element is designed to create a cohesive, polished look.

## 🛠️ Crafted With

- **HTML5** — page structure and content.
- **CSS3** — styling, layouts, animations, and responsive design.
- **JavaScript** — search, product rendering, and interactive features.
- **Local Storage** — storing favorites and other browser-side data.
- **GitHub Pages** — hosting and publishing the website.

## 🚀 How to Explore

1. Open the live website.
2. Browse the handbag collection.
3. Use the search feature to find a handbag.
4. Select **View Details** to explore a product.
5. Choose a quantity and try the **Add to Bag** functionality.
6. Save or remove handbags from your favorites.

To run the project locally, download or clone the repository and open the appropriate HTML page in your browser.
