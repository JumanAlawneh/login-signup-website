## ✨ Overview

**Luxe Bags** is a fashion-inspired handbag website that combines an elegant black-and-gold aesthetic with interactive front-end functionality.

Designed to showcase handbags inspired by iconic luxury fashion brands, the project brings together product discovery, search, favorites, product details, and shopping bag management in one cohesive web experience.

The project demonstrates practical front-end development skills, responsive interface design, and client-side data management.

## 💎 Key Features

| Feature | Description |
|---|---|
| 🖤 Luxury Interface | A sophisticated black-and-gold visual identity. |
| 👜 Product Collection | Browse a curated collection of fashion-inspired handbags. |
| 🔎 Product Search | Find products by available names, brands, or descriptions. |
| ✨ Product Details | Explore individual product information and imagery. |
| ♡ Favorites | Save favorite products using browser storage. |
| 🛍️ Shopping Bag | Add products, adjust quantities, and remove items. |
| 🧾 Order Summary | Review selected products and calculated totals. |
| 🔐 Login Interface | A dedicated login page. |
| 📝 Registration Interface | A separate sign-up page. |
| 📱 Responsive Design | Layout adjustments for desktop and mobile screens. |

## 🛠️ Technology Stack

- **HTML5** — page structure and semantic content.
- **CSS3** — styling, layouts, visual effects, and responsive design.
- **JavaScript** — interactive features and dynamic page behavior.
- **Local Storage** — client-side persistence for supported favorites and shopping bag data.
- **GitHub Pages** — website hosting and deployment.

## 🚀 Getting Started

### Explore the Live Website

Visit the deployed website:

**[Open Luxe Bags →](https://jumanalawneh.github.io/luxe-bags/)**

### Run Locally

1. Open the repository on GitHub.
2. Select **Code → Download ZIP**.
3. Extract the downloaded folder.
4. Open the project folder.
5. Launch `index.html` in your browser.

For the best experience, keep the HTML files and image assets in their expected locations.

## 🎨 Design Philosophy

Luxe Bags follows a visual direction inspired by modern luxury retail:

- **Midnight Black** — elegance and contrast.
- **Signature Gold** — refined highlights and visual accents.
- **Editorial Product Layouts** — organized product presentation.
- **Glass-Inspired Panels** — translucent surfaces and subtle blur effects.
- **Responsive Components** — layouts designed to adapt to different screen sizes.

## 🛍️ Shopping Bag & Data

The shopping bag interface is designed to let users review selected items, change quantities, remove products, and view updated totals.

Where implemented, browser `localStorage` allows supported data to persist between pages in the same browser.

> **Project Scope:** Luxe Bags is a front-end demonstration. It does not implement real payment processing or a production-ready checkout system.
